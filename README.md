
# ASSISTENTE-MZ-IA MZ

## Resumo
Assistente inteligente para redes sociais, feito em Moçambique. O ASSISTENTE-MZ-IA ajuda a responder mensagens, organizar tarefas e automatizar o atendimento no WhatsApp, Facebook e outras redes sociais, de forma rápida e simples.

## O que faz
- Responde mensagens automaticamente
- Organiza tarefas
- Automatiza o atendimento nas redes sociais
