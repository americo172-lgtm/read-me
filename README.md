
# ASSISTENTE-MZ-IA 🇲🇿

Assistente inteligente para WhatsApp, feito em Moçambique.

O ASSISTENTE-MZ-IA ajuda a responder mensagens, organizar tarefas e automatizar o atendimento no WhatsApp, de forma rápida e simples.

## O que faz

- Responde mensagens automaticamente no WhatsApp
- Ajuda a organizar tarefas e lembretes
- Funciona 24h por dia
- Fácil de usar e de configurar

## Tecnologias

- Node.js
- JavaScript
- WhatsApp API
- GitHub

## Como usar

1. Clona o repositório
2. Entra na pasta do projeto
3. Instala as dependências com npm install
4. Inicia o projeto com npm start
