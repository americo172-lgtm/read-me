# github.com-americo-lgtm-assistente

## Resumo
ASSISTENTE-MZ-IA é um assistente virtual de Moçambique que ajuda os utilizadores a escrever textos, responder perguntas, criar ideias e organizar tarefas de forma simples e rápida, diretamente no navegador.

## Como usar
Abra o ficheiro index.html no navegador e comece a conversar com o assistente.
